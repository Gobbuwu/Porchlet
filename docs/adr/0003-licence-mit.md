# 0003. Licence: MIT

- Status: Accepted (2026-11-23, by Gobbu)

## Context

Porchlet is open source and each operator runs their own copy, possibly for paid client work.

## Decision

MIT ([LICENSE](../../LICENSE)). It lets operators run and change their copy for any use without sharing changes back.

## Consequences

- Anyone can fork it, including into closed products.
- Every dependency's licence must be compatible; new dependencies get a licence note in their PR.
- A lawyer reviews the licence and legal files before the first public release (v0.1.0).
